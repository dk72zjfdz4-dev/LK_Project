# Правила проекта

- Сохраняй обязательное ядро конкурса при любых изменениях. Дедлайн — 22 ноября 2026 года, доступность опубликованной версии — до 28 ноября. Публикация и платные действия требуют согласования.
- Используй только вымышленные персональные данные, оригинальные материалы или материалы с разрешающей лицензией. Без официального логотипа и подключения к системам вуза. Отмечай демонстрационные сведения. Помощник работает по FAQ без внешней ИИ-модели.
- Сервер проверяет роль и принадлежность ресурса по сессии при чтении и изменении. Храни пароли как стойкие хеши с отдельными солями, проверяй формат и размер вложений и выдавай файлы только авторизованным пользователям. Секреты, рабочая база, загрузки и результаты тестов исключены из Git и публичной выдачи.
- Поддерживай ширину от 360 px, работу с клавиатуры и видимый фокус. Для браузерных проверок используй отдельный Playwright-браузер с временной базой. Личный браузер и управление компьютером пользователя запрещены.
- Выбирай модель и объём проверок по сложности. Предпочтения: GPT-6.2 Sol / Medium для основной работы, Sol / High для сложных прав, безопасности и ошибок, Sol / Low для механических правок. Используй доступные настройки, Astra и режимы выше High автоматически не включай.
- Максимум два помощника одновременно, один ответственный на файл. Перед делегированием зафиксируй файлы, модель и критерий готовности. Главный агент согласует API и объединяет результаты.
- Проверяй завершённый этап по затронутым сценариям. Полный набор повторяй при риске регрессии или по требованию этапа. Записывай фактические результаты в прогресс и сохраняй безопасный коммит с проверенным списком файлов.
