# Правила проекта

- Дедлайн конкурса — 22 ноября 2026. Поддерживать опубликованную версию до 28 ноября. Платные действия и внешняя публикация требуют согласования условий.
- Использовать вымышленные данные, оригинальные материалы и разрешающие лицензии. Без официального логотипа, интеграций с вузом, ИИ-чата и дополнительных сервисов.
- Источник владельца ресурса — серверная сессия. Проверять владельца при каждом чтении и изменении. Пароли хранить как стойкие хеши с отдельными солями. Рабочие секреты и файлы базы держать вне репозитория и публичных каталогов.
- Главный агент ведёт контракт, интеграцию, зависимости и общие настройки. Целевой режим GPT-6.2 Sol / Medium. Для доступа и сложных ошибок — Sol / High. Механические правки — GPT-6 Luna / Low при наличии, иначе предложить Sol / Low. Astra и Xhigh+ автоматически не выбирать.
- Одновременно максимум два помощника. Перед стартом зафиксировать модель, усилие, файлы и критерий готовности. Интерфейс работает только в public/, сервер — в server.mjs и cabinet.mjs. Изменения контракта согласовать с главным агентом. Итог помощника — изменённые файлы и реальные проверки.
- Запуск: `npm start`. Проверки: `npm run build` и `npm test`.
