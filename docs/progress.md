## Как открыть

Откройте http://127.0.0.1:3000/. Логины — `student1` и `student2`. Пароли лежат в локальном игнорируемом файле `data/local-demo.env` с правами доступа только для владельца. `DEMO_PASSWORD_1` соответствует первому логину, `DEMO_PASSWORD_2` — второму.

Если сервер остановлен, выполните `npm start` в папке проекта. При запуске с чистой базой из интерактивного терминала сервер выводит сгенерированные пароли. Для текущей базы используйте сохранённые пароли. Команда `node server.mjs --reset-demo-passwords` создаёт новые пароли и завершает обе демо-сессии. После сброса значения из файла прежние.

### Ручная проверка в браузере

1. При 360 px открыть меню по аватару под каждой ролью. Проверить доступные разделы, выход, циклический фокус, Escape, кнопку закрытия и нажатие на фон. После закрытия фокус должен вернуться к аватару, прокрутка — восстановиться.

3. В длинном диалоге прокрутить вверх, получить новое сообщение из второй сессии и убедиться, что позиция чтения сохранилась. Повторить у нижнего края и после собственной отправки.

## Браузерные тесты

`npm run test` запускает обычные тесты. Для первого браузерного запуска выполните `npm ci` и `npx playwright install chromium`, затем `npm run test:browser`. Playwright Test также видит сценарии из `e2e/` через `playwright.config.mjs`.

Тесты используют отдельный headless Chromium, временную SQLite, вымышленные учётные записи и случайный порт на 127.0.0.1. Скриншоты 360 px сохраняются в `test-results/screenshots/`. Папки с результатами исключены из Git.

19 ноября 2026 года в Chromium проверены ширины 360 и 440 px, вход студента и преподавателя, левое меню, Escape и видимый фокус, поиск и форма справки, сообщение с переносом, помощь и выбор корпуса. Снимки главной, меню, поиска и карты на 360 px просмотрены. Проверка выполнена с узким viewport в Chromium.
