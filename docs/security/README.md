# Защитное ревью «Орбиты»

Исходная точка — `0f39885`, метка `checkpoint-before-security-review`. Проверяются исходники и штатные сценарии на loopback. Рабочая база, процесс на порту 3000, публичный сайт и внешние сервисы исключены. Нагрузочные проверки и подбор паролей не выполняются.

## Матрица прав

Матрица основана на [требованиях](../requirements.md) и [контракте API](../api-contract.md). «Своё» определяется сессией. Назначение, участие и состояние ресурса проверяет сервер.

| Роль | Объект | Разрешено |
|---|---|---|
| Гость | Страница входа и публичные ресурсы | Открыть интерфейс, войти. Доступ к персональным данным требует сессии |
| Студент, преподаватель, деканат | Сессия, профиль, поиск | Читать собственный профиль. Искать в доступной части каталога и данных. Отозвать собственную сессию |
| Студент | Расписание и оценки | Читать собственное расписание, занятия, опубликованные оценки и итоги |
| Студент | Запрос и справка | Подать и читать свои запросы. Скачать файл по своей действующей доставке |
| Студент | Задания, работы, пересмотр | Читать свои задания, загрузить и скачать свою работу, подать или отозвать допустимый пересмотр |
| Студент | Портфолио и рекомендации | Управлять своими достижениями, отправлять назначенному проверяющему, запрашивать рекомендацию, читать опубликованные версии и экспортировать доступное |
| Преподаватель | Расписание, журнал, курсовые работы | Управлять своими занятиями и записями по назначенным предметам и группам. Проверять назначенные работы и пересмотры. Для исправления баллов действует исходный срок |
| Преподаватель | Портфолио | Проверять назначенные ему записи в действующей области доступа. Вести и публиковать свои рекомендации. Экспорт ограничен договорённым набором |
| Деканат | Запросы и справки | В текущем демо очередь охватывает всех студентов. Взять в работу, проверить файл, отправить конкретному владельцу и отозвать доставку |
| Деканат | Портфолио | Проверять назначенную запись при явной привязке к группе. Экспортировать только разрешённые записи |
| Деканат | Объявления | Публиковать студентам, преподавателям или обеим ролям. Читать историю |
| Студент, преподаватель | Объявления | Читать уведомления своей аудитории |
| Участник диалога | Диалог, сообщения, обычные вложения | Читать видимые сообщения и вложения. Писать, подтверждать входящие. Удалять у себя. Автор может удалить у всех до прочтения |
| Любая роль с сессией | Закрытые файлы и изменяющие запросы | Доступ зависит от объекта и его состояния. Сервер проверяет формат и размер файла. Изменяющие запросы проверяются по тому же origin |

Студенческий каталог контактов и обмен карточками профиля в разрешённом диалоге описаны в контракте. Эта функция отличается от доступа к личному кабинету другого пользователя. Очередь справок и портфолио используют разные согласованные области деканата.

## Порядок проверки

1. Зафиксировать SHA и сохранить копии затрагиваемых пользовательских правок в игнорируемой папке. Исходники для проверки извлечь в отдельный каталог. На этом этапе использован архив Git, чтобы не делить редактируемые файлы между агентами.
2. Использовать установленные зависимости и штатные фикстуры. На зафиксированной копии запустить `node --test test/*.test.mjs`. Каждый серверный тест создаёт временную SQLite и слушает свободный loopback-порт.
3. На той же копии запустить Playwright с фильтром `dean announces|dean sends|message deletion|portfolio and PDF`. Для вложенной копии этапа команда `node ../../../node_modules/playwright/cli.js test --grep 'dean announces|dean sends|message deletion|portfolio and PDF'`.
4. Охотник проверяет исходную версию. Защитник меняет только назначенные файлы. Координатор фиксирует исправление и регистрирует отдельную повторную проверку. Секреты и сырые тестовые данные в Git не помещаются.
