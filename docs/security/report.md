# Отчёт о защитном ревью «Орбиты»

22 ноября 2026 года. Проверка конкурсного прототипа выполнена на фиксированных копиях `0f39885` и `53dcec2` с временной SQLite, динамическими loopback-портами и вымышленными аккаунтами. Проверялись два студента, преподаватель и деканат. В отдельных штатных сценариях есть второй преподаватель. Внешние интеграции не задействовались. Рабочий процесс, рабочая база и публичный сайт в проверку не входили.

## Команда и журнал действий

| Этап | Исполнитель | Результат |
|---|---|---|
| Подготовка | Координатор | Прочитаны AGENTS.md, требования, API и известные дефекты. Проверен Git. Шесть локальных правок сохранены в `.recovery/security-review-20261122/working` и сверены по хешам. Создана метка `checkpoint-before-security-review` на `0f39885`. Для проверок извлечены архивы зафиксированных исходников |
| Независимая проверка базы | Охотник, GPT-6.2 Sol / High | Пройдены штатные тесты, просмотрены серверные области и клиентские способы вывода текста. Определён источник SEC-001 |
| Исправление | Защитник, GPT-6.2 Sol / High | Добавил ограниченную очередь проверки пароля и модульную регрессию. Изменял только назначенные файлы. Координатор проверил diff и зафиксировал `53dcec2` |
| Повторная проверка | Охотник, GPT-6.2 Sol / High | Сверил изменённые файлы изолированной копии с Git и независимо прогнал три целевых теста. SEC-001 закрыт |
| Контрольный проход | Координатор | Прогнаны тесты проекта до и после правки, проверены хранение учётных данных и отсутствие распознанных секретов в отслеживаемых текстах. Результаты внесены в реестр |

Один стартовый вызов Playwright использовал неверный относительный путь к установленным зависимостям. После исправления пути тесты стартовали. При одном запуске Защитника команда `node --test` без путей автоматически включила соседние `v2/test` и получила там пять отказов. Версию коллеги вручную не изучали и не правили. Этот запуск исключён из результата, все зачтённые проверки ограничены зафиксированными копиями или файлами `test/*.test.mjs` основного проекта.

## Проблема, исправление и подтверждение

| Проблема | Исправление | Подтверждение |
|---|---|---|
| [SEC-001](findings/SEC-001.md). Неограниченная прикладная очередь проверки паролей | Ограничение параллельных операций и ожидания в `53dcec2` | Модульная регрессия и три независимых целевых теста. HTTP-ветка 429 сверена по коду |
| [SEC-002](findings/SEC-002.md). Частота последовательных попыток | Отложено до согласования эксплуатационной политики | Отсутствие отдельного правила установлено по исходникам. Частые попытки на HTTP не проверялись |

По итогам этого прохода серьёзных открытых нарушений контроля доступа не подтверждено. SEC-002 остаётся открытой задачей средней серьёзности для публичного размещения.

## Выполненные проверки

- На `0f39885` координатор выполнил 21/21 тест Node.js и 7/7 сценариев Chromium. Охотник независимо выполнил 21/21 тест Node.js на исходной копии.
- На `53dcec2` координатор выполнил lint, сборку, проверку синтаксиса нового модуля, 22/22 теста Node.js, 7/7 сценариев Chromium и отдельную проверку хеширования паролей и сессий. Охотник независимо выполнил 3/3 целевых теста. Браузерные сценарии включали 360, 440 и 1440 px в эмуляции.
- Сценарии Chromium охватывают удаление сообщений, разделение аудиторий объявлений, обе доставки справок с отзывом и повторной выдачей, портфолио и скачивание PDF. Физические устройства не использовались.

## Ограничения и действия перед публикацией

- Проверить конфигурацию доверенного HTTPS-origin и атрибут `Secure` у cookie в целевом окружении. Локальные тесты проверили `HttpOnly` и `SameSite=Strict`. Публичный прокси, внешние сервисы и транспорт вне loopback не проверялись.
- Согласовать частоту входа по SEC-002 и эксплуатационные ограничения на суммарное хранение версий файлов. Серверные лимиты отдельных файлов проверены. Нагрузочные проверки, подбор паролей и динамическая проверка насыщения очереди не выполнялись.
- Подтвердить полномочия нескольких сотрудников деканата, если потребуется деление очереди по группам. Сейчас справки доступны роли деканата согласно демо-контракту. Отдельной проверки между двумя сотрудниками деканата не было.
- Проверка секретов ограничена контрольными форматами и зафиксированными исходниками. Рабочие значения, системные журналы и конфигурация публикации не исследовались.

Миграции SQLite нет. Код SEC-001 можно вернуть отдельным `git revert 53dcec2`. Для применения исправления потребуется плановый перезапуск Node. В ходе ревью рабочий процесс не перезапускался.
