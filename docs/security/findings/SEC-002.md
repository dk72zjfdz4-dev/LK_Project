# SEC-002 — Частота последовательных попыток входа

- **Статус** — Отложено.
- **Серьёзность** — средняя для публичного размещения.
- **Проверенные версии** — `0f39885`, `53dcec2`.

## Условия и наблюдение

Проверка по исходникам локального обработчика входа и [ранее зарегистрированному наблюдению](../../bugs.md). Ограничение SEC-001 регулирует конкуренцию и ожидание. Отдельной политики последовательных неудачных попыток на аккаунт или источник нет в проверенном коде. При публичном размещении нужна согласованная политика, которая ограничивает частые повторные попытки и сохраняет доступ для законных пользователей.

Подбор паролей и проверка порогов на работающем HTTP не проводились. Настройки публичного прокси и возможные дополнительные ограничения вне исходников не проверены.

## Оставшиеся действия

Определить правила с учётом доверенного прокси, общего адреса у нескольких пользователей и восстановления доступа. После реализации проверить политику модульно и штатный вход отдельным регрессионным сценарием. Коммита исправления и независимой повторной проверки для этой находки пока нет.
